# trading-data-public

Automated market-data mirror. **No account information** — market data and derived signals only.

Auto-published each weekday by [trading-automation-v5](https://github.com/Razorghost87/trading-automation-v5).
Do not edit by hand; files here are overwritten on every run.

| File | Contents |
|---|---|
| `digest-latest.md` | Formatted daily digest (macro, regime, state signals, movers, funnel) |
| `regime.json` | Basket rotation ranks + rate overlay |
| `states-latest.json` | Unified state taxonomy (S1–S4) per ticker |
| `macro.json` | Macro posture (rates, credit, vol, breadth) |
